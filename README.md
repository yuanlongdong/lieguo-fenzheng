# 列国纷争 - 抖音弹幕互动对抗游戏
> 战国七雄阵营对抗，点赞产兵、刷礼物召唤武将、合纵连横攻城略地

## 项目简介

《列国纷争》是一款参考抖音《三国战纪：百家版》的弹幕互动对抗游戏。观众通过弹幕加入战国七雄阵营，点赞产兵、刷礼物召唤武将与释放技能，在列国地图上攻城略地，灭国淘汰，最终一统天下。

核心差异化：**合纵连横外交系统**——劣势阵营可结盟抗强，强势阵营可用离间计分化，背盟机制制造戏剧性。

## 游戏特性

- **七雄争霸**：秦、楚、齐、燕、赵、魏、韩，每国独特国战特性
- **21座城池**：首都、重镇、普通城，战略价值各异
- **12名武将**：橙/紫/蓝三品质，被动光环+主动技能，可升级
- **10种礼物**：从1抖币灯牌到3万抖币嘉年华，效果各异
- **合纵连横**：结盟、背盟、离间计，外交博弈改变战局
- **实时战斗**：自动攻城，耐久削减，城池易主，灭国淘汰
- **模拟控制面板**：无需真实抖音接入，本地即可体验完整玩法

## 游戏玩法

### 基本流程
1. **开始游戏** → 点击"开始游戏"按钮
2. **选择阵营** → 加入战国七雄之一
3. **免费互动** → 点赞产兵、发弹幕增兵
4. **刷礼物** → 召唤武将、释放技能、攻城略地
5. **合纵连横** → 结盟抗强或背盟偷袭
6. **一统天下** → 灭掉其他六国获胜

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript（ES6+）

- 无外部依赖，开箱即用

## 接入真实抖音弹幕

当前版本使用模拟控制面板。接入真实抖音开放平台需要：
1. 申请抖音开放平台权限
2. 使用抖音弹幕/礼物 WebSocket 接口
3. 将 `ui.js` 中的模拟按钮替换为真实事件监听
4. 服务端做弹幕鉴权和礼物结算

核心游戏逻辑（`game.js`）无需修改，只需替换输入层。
